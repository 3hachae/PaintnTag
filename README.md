# 개요 / 概要
PaintnTag는 지도 덕후들을 위해 제작되고, 디자인되었습니다.\
PaintnTagは、地図オタクのために、制作、デザインされました。
## 지원 범위 / 対応範囲
* 한국과 일본의 지도를 지원합니다.\
  韓国及び日本の領土に対応しています。
# 사용 방법
## 색칠 / 塗りつぶし
* 색칠하고 싶은 지역의 이름을 적거나, 직접 지도에서 선택하여 색칠할 수 있습니다.\
塗りつぶしたい地域名を入力するか、地図上で直接選択して塗りつぶすことができます。
* 다수의 지자체를 한꺼번에 입력하는 기능도 지원합니다. 특별시, 도 등의 상위 지자체는 일괄 입력 기능을 쓰지 않고도 검색창에서 입력할 수 있습니다.\
  複数の自治体を一度に入力する機能にも対応しています。都道府県などの上位の自治体は、一括入力機能を使わなくても検索ボックスから入力できます。
* 모든 한국 지자체에 대해 로마자 입력 기능을 지원합니다.\
  韓国のすべての自治体について、ローマ字入力に対応しています。

  별개로 큐슈 및 도쿄를 제외한 나머지 일본 지자체에 대해서는, 모든 지역에 대해서 로마자 입력 기능을 지원한다고 장담하기 어렵습니다. 되도록 일본명으로 입력 부탁드립니다.\
  なお、九州および東京都を除くその他の日本の自治体については、すべての地域でローマ字入力に対応しているとは限りません。できるだけ日本語名で入力してください。

## 다운로드 / ダウンロード
* 지도를 다운로드 할 때는 현재 표시하고 있는 화면을 기준으로 사진이 출력됩니다.
  地図をダウンロードする際は、現在表示している画面を基準にイメージが出力されます。

  화질이 낮거나 색칠된 부분이 잘 보이지 않을 수 있습니다.\
  画像の品質が低い場合や、塗りつぶした部分が見えにくい場合があります。
## 설정
* 설정에서 화면 모드를 바꿀 수 있습니다. 라이트모드를 추천합니다.\
  設定から画面モードを切り替えることができます。ライトモードを推奨します。
  
* 언어 변경이 가능합니다. 현재 지원하는 언어는 한국어, 영어, 일본어입니다. 개발자가 못 하는 언어는 추가할 생각이 없습니다.\
  言語を切り替えることができます。現在対応する言語は英語、日本語、韓国語です。開発者ができない言語は、追加するつもりがありません。

* 특별한 화면 모드가 숨겨져 있습니다. 잘 찾아보세요. 참고로 찾아도 선물은 없습니다.\
  特別な画面モードが隠されています。ぜひ見つけてみてください。ちなみに見つけてもプレゼントはありません。
